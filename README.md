# Smart-ATM-System
## Project Description
The Smart ATM System is a beginner-friendly Python project that simulates the basic functionality of an ATM. It allows users to verify their PIN, check account balance, deposit money, withdraw money, or exit the system. This project is created to practice operators and conditional statements in python.
## Objectives
- Learn how to use operators in python.
- Understand conditional statement(if, elif, else).
- Build a simple real-world command-line application.
- Improve python programming skills.
## Topic Explanation
1. Operators<br>
Operators are special symbols in python that perform operations on variables and values. They help the program performs calculations, compare values, assign data, and make logical decision. Different types of operators are used depending on the task being performed.<br>
In this project, arithmetic operators are used to update the account balance after depositing or withdrawing money, while comparison operators are used to verify the ATM PIN and check wheather the account has sufficient balance<br>
2. Conditional Statements<br>
Conditional statements allow a program to make decision based on specific condition . They control the flow of execution by running different blocks of code depending on whether a condition is True or False.<br>
Python provides three main conditional statements:<br>
- if = Executes a block of code when the given condition is true<br>
- elif = Check another condition if the previous condition is false<br>
- else = Executes a block of code when none of the previous conditions are true.
